Quant signal-evaluation insights (added 18-Jun-26, APM — RS-Momentum review)

  • Judge Signals on Excess, Not Absolute, Returns [Bronze] — general/investing — measure alpha, not beta; absolute returns flatter signals in rising markets.
  • Persistence Is Not Prediction [Bronze] — general/decision-making — overlapping look-backs make level-autocorrelation mechanical; test forward return directly.
  • Robustness Quartet Before Conviction [Bronze] — general/decision-making — liquidity, skip-a-period, regime split, survivorship before trusting any signal.
  • Cross-Sectional vs Time-Series Momentum [Bronze] — situational/portfolio-construction — distinct, can oppose; cross-sector momentum is regime-conditional, within-sector mean-reversion is robust.
  • Shadow Concentration via Shared Cohort — bronze (1 conf.) — two live holdings sharing one cohort/thesis is invisible to per-position review; only a deliberate cross-holding check surfaces the combined thematic weight (Arteche/Alfen, ~6.6% of assets, 07-Aug-26).
  • Chemicals: Single-End-Market Concentration Fails the Downturn-Robustness Test — bronze (1 conf.)
  • Chemicals Sector GDP-Gearing: A Geared, Not Hedged, Cyclical Play — bronze (1 conf.)
