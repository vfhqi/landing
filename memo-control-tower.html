How to read this board: a card is one request for one memo; it moves through the trays as scripts and the model calls act on it, and every step writes a dated line into its history. The ladder marks where a card sits among Requested, Readiness check, Ready, Analysis, Writing, Checks and page, and Published; "unknown" means the history could not support even that much, and is never guessed. "Tokens, three calls" is a measurement from the run where recorded, otherwise "not recorded". A time is never estimated: where a card has no history it says "unknown". The next scheduled run time cannot be read from any file on disk, so it is not shown here.
