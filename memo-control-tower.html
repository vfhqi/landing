How the arrival estimate works. A memo still needs a number of dispatch fires to finish: about one if it is already judged, three if it is being audited, more if it is still being written. Fires run every 60 minutes and carry up to 10 memos, so a memo also waits its turn in the queue. The estimate multiplies the two. It is an estimate, not a promise — a memo that fails an audit round takes another lap. Blocked and awaiting-you items deliberately show no estimate, because the line will not clear them by itself.
