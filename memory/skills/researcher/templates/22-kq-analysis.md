## MISSION

Framework-driven ANALYSIS of a specific KEY QUESTION (KQ): competing hypotheses, decision logic, judgement-heavy assessment. Output: peer-anchored, signposted, J-front + sceptical-bullet memo applying Heuer's ACH discipline as the structural spine, surfacing the hypothesis with FEWEST hard inconsistencies, with explicit means/motive/opportunity application, and explicit multiple-truths-coexist treatment where evidence supports multiple partial truths. ≥3,000w per source ([C] + [AS]).

**Q22 vs Q21 differentiation:**
- **Q21 = BROAD RESEARCH KQ.** Landscape mapping. What is the territory?
- **Q22 (this template) = ANALYTICAL KQ.** Given the landscape, what is the JUDGEMENT? Which competing hypothesis is most likely? Synthetic, judgement-forming, ACH-disciplined.

If a Q22 is run before a Q21 on the same KQ, the analyst is skipping the landscape work — usually a mistake. Q21 + Q22 paired is the strongest sequence.

## CONTEXT — What the reader cares about

**Audience:** Concentrated long-only equity investor (5-15 positions), UK/Europe focus, $5-50bn market cap sweet spot. Holds 12-24 months. Singular focus: predictable 18M-3Y EPS trajectory with 25%+ IRR potential.

**Stage — any (typically ESA or DD onwards).** Q22 is the analytical KQ — the stage where judgement is forced. The output is a verbal verdict with stated competing hypotheses, NOT a hedge.

**What downstream uses this output:** APM uses Q22 ACH matrix to inform pillar-level grading where the KQ is on the critical path. Memo also surfaces on RESEARCH STAGES dashboard tab in one of three ad-hoc KQ slots.

**Canonical taxonomy reference (per D-RSR-33):** the authoritative source is `memory/skills/assistant-portfolio-manager/analysis-judgement-SOP.md`. Hierarchy: **Pillar > Group (BB#) > Element / TC > Required Attribute (RA) > Core Question (CQ)**. Q22 typically targets a single RA or sub-question that's load-bearing. RESEARCHER does NOT grade — APM grades.

**Mental models (LOAD-BEARING for Q22):**
- **Heuer's Analysis of Competing Hypotheses (ACH)** — IS the structural spine. ≥3 hypotheses, evidence × hypothesis matrix, winner = fewest hard inconsistencies (per Wisdom Library Gold `analysis-of-competing-hypotheses-heuer`).
- **Strong views, weakly held** — always conclude with a verbal verdict, NEVER hedge into "it depends". The verdict is updateable as new evidence arrives, but it must exist.
- **Inversion (Jacobi / Popper)** — apply explicitly. What would invalidate the leading view?
- **Multiple truths coexist (Concept B CRITICAL ACTION 3)** — where evidence supports multiple hypotheses partially, name the elephant. The judgement may be that BOTH partial truths hold under different conditions.
- **Means / Motive / Opportunity (Concept A)** — apply per hypothesis. Hypotheses that fail one or more legs drop out faster.
- **Power of incentives (Concept A — Munger)** — for each information source, name the incentive lens before weighing the content.
- **The obstacle is the way (Concept B CRITICAL ACTION 1 — Marcus Aurelius)** — engage the most-different evidence, don't rationalise it away.
- **Stewing (Concept B CRITICAL ACTION 2)** — Q22 is the structural moment to stew. Don't conclude in the first 30 minutes.

## SECTIONS TO COVER

### §1 — KQ definition + Mission Command brief + competing hypotheses

**Open with J-front verdict bullet:** ACH winner — which of the ≥3 competing hypotheses has the FEWEST hard inconsistencies — ≤30w peer-anchored.

**Required content:**
- KQ stated verbatim (≤30w).
- Higher intent (why does the analyst care? What decision rides on the answer?).
- ≥3 competing hypotheses enumerated, mutually exclusive, collectively exhaustive. State each as a falsifiable claim. Include the "null / neither" hypothesis where applicable.
- Stage context.

**Coverage:** 8-12 parent bullets.

**End with sceptical bullet:** "What's the runner-up hypothesis? Why isn't it the winner — what disconfirming evidence did it accumulate?"

---

### §2 — Evidence catalogue (organised by source incentive — Concept A)

**Open with J-front verdict bullet:** Net signal on evidence breadth + source-incentive distribution — is the catalogue dominated by sources with aligned incentives (suspect) or balanced (load-bearing)? — ≤30w.

**Canonical signpost vocabulary:** "Source category:", "Incentive lens:", "Aligned source:", "Adversarial source:", "Triangulating source:", "Cross-checked:", "Single-source claim:", "Source diversity:". Invent where pattern warrants.

**Required treatment per evidence item:**
- Evidence item (≤30w).
- Source.
- **Source incentive** (per Concept A power-of-incentives — what is the source incentivised to disclose / withhold / amplify / suppress?).
- Confidence rating (high / medium / low).

**Coverage:** ≥15 evidence items, 12-18 parent bullets + sub-bullets.

**End with sceptical bullet:** "What evidence is the analyst NOT seeing because the source pool is incentive-aligned? Apply Concept B CRITICAL ACTION 1 — go to the most-different source."

---

### §3 — ACH MATRIX (LOAD-BEARING ARTEFACT)

**Open with J-front verdict bullet:** ACH winner with disconfirming-evidence count per hypothesis — ≤30w.

The ACH matrix is the structural deliverable of Q22. Format:

| Evidence item | Hypothesis A (consistent? +/-/N) | Hypothesis B (consistent? +/-/N) | Hypothesis C (consistent? +/-/N) | (more cols if needed) | Diagnostic? |
|---|---|---|---|---|---|
| Item 1 | + | - | + | ... | yes |
| Item 2 | - | + | - | ... | yes |
| ... | ... | ... | ... | ... | ... |
| **Disconfirming evidence COUNT (lower = better)** | **N_A** | **N_B** | **N_C** | ... | — |

The hypothesis with the LOWEST disconfirming-evidence count is the ACH winner. Diagnostic items get "yes" — those discriminate hardest between hypotheses and are highest-priority data-gathering targets.

**Required:** ≥15 evidence items. ≥6 diagnostic items. ACH winner stated explicitly.

**Coverage:** matrix + 8-12 interpretation bullets.

**End with sceptical bullet:** "What new evidence would flip the ACH winner? What is the sensitivity of the verdict to a single new diagnostic finding?"

---

### §4 — Per-hypothesis assessment (incl. M/M/O test)

**Open with J-front verdict bullet:** Net signal on which hypothesis has the strongest causal architecture (means + motive + opportunity all aligned) — ≤30w.

For each hypothesis enumerated in §1:
- Causal mechanism (transmission path: action → outcome).
- **Means/Motive/Opportunity test** (per Concept A): does the hypothesis name an actor with all three legs aligned? Hypotheses missing one or more legs drop priority.
- Strongest supporting evidence (≤25w each — top 3).
- Strongest disconfirming evidence (≤25w each — top 3).
- Verbal verdict: "high plausibility / medium plausibility / low plausibility".

**Coverage:** 12-18 parent bullets + sub-bullets across all hypotheses.

**End with sceptical bullet:** "Which hypothesis is the analyst flinching from? Per the obstacle is the way (Concept B / Marcus Aurelius), engage it explicitly."

---

### §5 — Multiple-truths-coexist synthesis (where applicable)

**Open with J-front verdict bullet:** Is the answer composite — do multiple hypotheses hold partially under different conditions? — ≤30w.

**Canonical signpost vocabulary:** "Composite answer:", "Conditional truth:", "Time-frame split:", "Segment split:", "Geographic split:", "Scenario split:", "Elephant view:", "Six-blind-men synthesis:". Invent where pattern warrants.

**When applicable:** if the §3 ACH matrix shows two hypotheses with similar disconfirming-evidence counts (close-call), the most likely truth is composite. Apply Concept B CRITICAL ACTION 3 (multiple-truths-coexist):
- Name the elephant — the underlying composite truth that contains both partial views.
- State which conditions favour which hypothesis (timeframe, segment, scenario).
- Surface what would shift the composite balance.

**When NOT applicable** (one hypothesis clearly dominates): briefly note and skip.

**Coverage:** 6-10 parent bullets (when applicable; 1-2 if skipped).

**End with sceptical bullet:** "If the truth is composite, has the analyst correctly identified the conditions, or is the synthesis itself a hedge?"

---

### §6 — Watson verbal verdict + monitoring triggers

**Open with J-front verdict bullet:** Watson verbal verdict on the KQ + monitoring triggers — ≤30w.

**Canonical signpost vocabulary:** "Watson verdict:", "Monitoring trigger:", "ACH-flip signal:", "Stewing recommendation:", "Stage progression hypothesis:", "Confidence interval:", "Strong views weakly held:". Invent where pattern warrants.

**Required:**
- Verbal verdict — "high plausibility / medium plausibility / low plausibility" of the leading hypothesis. NOT a probability number (RESEARCHER doesn't grade).
- ≥3 monitoring triggers — what data, if observed, would shift the verdict?
- Stewing recommendation (per `stewing-and-the-valley-of-despair` Wisdom Library Gold) — what specific contradictions should the analyst stew on before lock-in?
- Stage progression hypothesis — does Q22 evidence support proceeding / parking / killing the case?

**Coverage:** 8-12 parent bullets.

**End with sceptical bullet:** "If the verdict is wrong, what's the most likely path by which it's wrong? What's the single early-warning signal for ACH-flip?"
