## Per-Thematic Folder Convention

For each active thematic, the subfolder contains:
1. `birth-justification.md` — original triggering signal, working hypothesis, falsification test, expected horizon, Richard's priors.
2. `monitoring.md` — catalyst calendar, leading indicators, invalidation triggers.
3. `links.md` — cross-references to PROJECTS/ working artefacts (memo, delta report, AS extracts), Notion Journal posts, Wisdom Library entries that emerged from this build.
4. `refresh-history.md` — log of refinements, regime-change events, Mode 1 batch results.
