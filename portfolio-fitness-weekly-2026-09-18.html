Suggestions for Richard’s consideration, not instructions to trade

How to read this page

The six components run in strict dependency order: each one is built from the one above it. If component 1 was thin this week, everything below inherits that thinness, and each section is required to say so rather than sound more confident than its evidence. The arithmetic never has the last word. Every score is a starting point that the judgement may overrule, and every overrule is stated and reasoned.
