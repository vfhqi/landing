# Network Effects

## Definition
Value of a product or service increases as more people use it. Creates powerful moats because competitors must overcome the installed base. Types: direct (social), indirect (marketplace), data, protocol.

## Why It Matters
Network effects are the strongest moat source when present. They create winner-take-most dynamics and make switching costs rise with the network's size.

## Application
When assessing competitive advantage: is there a network effect? If yes, what type? How defensible is it? Can a competitor build a parallel network? What's the minimum viable network size?

## Examples from Track Record
- Metacognition item: two-sided networks, open marketplaces, social networks, physical networks (fibre, railways).
- Market cap vs TAM: can the network genuinely 5x from here?
