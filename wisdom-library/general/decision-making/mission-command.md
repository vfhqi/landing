# Mission Command (von Moltke)

## Definition
Six elements for delegating work: Context, Higher Intent, Objective, Suggested How, Constraints, Resources. Give clear intent and constraints, not step-by-step instructions. The subordinate has freedom to adapt within the intent.

## Why It Matters
Prevents micromanagement while maintaining alignment. The receiver can adapt to changing circumstances because they understand the WHY, not just the WHAT.

## Application
Parse every brief into Mission Command format before starting. State the parse explicitly for complex briefs. If any element is missing, ask before proceeding.

## Examples from Track Record
- Watson's core delegation framework. Used for all research briefs, task delegation, and sub-agent management.
- Back-brief protocol: restate task understanding before and after execution.
