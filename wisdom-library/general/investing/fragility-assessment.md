# Fragility Assessment (Forces x Fragilities = Movement)

## Definition
Assess fragility across four dimensions: Revenue (stability, concentration, contract duration, pricing power), Margin (operating leverage, cost stability, NWC), Financial (P&L leverage, FCF, covenants), Market Structure (short interest, liquidity, shareholder base, sentiment). Forces x Fragilities = Movement.

## Why It Matters
Systematic fragility assessment prevents the 'it looks fine until it isn't' problem. Each dimension can be independently stressed.

## Application
Run full fragility assessment at ESA stage. Any dimension rated D or below is a structural risk. Combined D ratings across multiple dimensions = exit signal.

- Portfolio Architecture: five diversification dimensions specifically address fragility concentration.
