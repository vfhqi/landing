# Disprove, Don't Prove (ACH)

## Definition
Don't solve for 'yes'. Build profiles of 'no', 'false friend', and 'yes'. Systematically test evidence against each. If the stock survives disproval, it might be an investment. Scientific method applied to investing.

## Why It Matters
Confirmation bias is the default human mode. Actively seeking disconfirming evidence is the only reliable antidote. Popper's falsification principle: a theory is only scientific if it can be disproven.

## Application
At every stage gate, run ACH explicitly. Three profiles: No (reasons this isn't an investment), False Friend (looks good but structurally flawed), Yes (genuine opportunity). Evaluate evidence against each.

## Examples from Track Record
- BFF: ACH threshold breached (shifted from 'yes' to 'no') but exit delayed. The framework worked — the execution didn't.
- HBX, Adevinta, S4, Nexi: all identified as false friends via ACH.
