# Key Questions Framework

## Definition
At every stage, the work produces a prioritised Key Questions list. KQs are the explicit gaps in conviction. By ESA, the top 3-5 KQs should define the research roadmap. By DD, all KQs must be answered or explicitly parked. If work doesn't address a KQ, don't do the work.

## Why It Matters
Prevents analytical rabbit holes. KQs force direction on research and prevent the 'gathering information without purpose' trap.

## Application
At every stage gate, state the KQs explicitly. After every research output, check: which KQs did this answer? Which remain? If a KQ can't be answered, is the stock investable?

## Examples from Track Record
- Marlowe project (2022): analysis without clear framing led to biased conclusions. KQ framework was the fix.
- Standing instruction: KQs can apply at any stage (IG through DD). Watson always asks 'Any specific KQs?'
