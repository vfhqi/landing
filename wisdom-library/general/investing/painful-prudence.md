# Painful Prudence (9-10/10 Bar)

## Definition
Only own stocks where conviction is genuinely 9/10 to 10/10. The opportunity cost of capital is high. If a stock is only 7/10, the capital is better deployed. Saying no to reasonable-but-not-exceptional ideas.

## Why It Matters
Prevents portfolio dilution. Every position below the 9/10 bar drags the portfolio toward mediocrity. The discipline of saying no is what creates room for the exceptional.

## Application
Before entry: run ACH ruthlessly. Can you disprove 'no' and 'false friend'? Only when both are disproven with high confidence is it a 'yes' worth acting on.

## Examples from Track Record
- Track record pattern: Best returns came from highest-conviction positions. Worst returns from 'sorta quality maybe' entries.
- BFF lesson: conviction eroded but position held — painful prudence should have triggered exit.
