# Love Portfolio Test

## Definition
Binary target condition: every week, Richard should be able to say every stock is 'loved here and now today' such that he'd be happy if it was 25% of AUM. If not, why not? Eliminates holdings that are 'just sitting there'.

## Why It Matters
The fastest diagnostic for portfolio quality. If a position can't pass the love test, it's consuming capital that should be deployed elsewhere.

## Application
Run weekly. For each position: 'Would I be happy if this was 25% of AUM?' If no, challenge why it's in the portfolio at all. If stretched valuation: trim. If thesis degraded: exit.

## Examples from Track Record
- Weekly review protocol: love test is the first check.
- When a stock is up a lot but fundamentals haven't improved and valuation is stretched: trim the winner.
