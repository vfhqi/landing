# Base Counting (Minervini)

## Definition
Tracks how many consolidation bases a stock has formed in its current advance. 1st-2nd base = lowest risk, full sizing. 3rd base = inflection — cut 25-50%, tighten stops. 4th-5th base = highest risk — tactical only. Count resets after full Stage 4 decline.

## Why It Matters
Provides objective, technical sizing calibration independent of fundamental view. Former leaders: 50% probability of declining 80% from peak, often while fundamentals still look intact.

## Application
Track base count for all live positions. At 3rd base: flag to APM, reduce sizing, tighten stops. At 4th+: tactical only, very tight stops, quick exit mindset.

## Examples from Track Record
- Minervini: VCP (Volatility Contraction Pattern) is the canonical base formation.
- APM responsibility: proactively flag when a stock reaches 3rd base.
