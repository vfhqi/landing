# Event Angle = Icing, Not Cake

## Definition
The event angle (special situation, catalyst, M&A) cannot be the main attraction of the investment thesis. It must be icing on a fundamentally sound cake. If the only reason to own it is the event, exit risk on negative node is too high.

## Why It Matters
Prevents event-driven positions without fundamental backing. These positions have binary risk that concentrated portfolios cannot absorb.

## Application
For every event-driven element: if the event doesn't happen, is the position still worth owning? If no, the event is the cake, not the icing. Reduce or avoid.

## Examples from Track Record
- Flatex: event angle was main attraction. Wrong setup for a concentrated portfolio.
- Nilfisk: event-driven thesis carrying concentration risk in operator quality.
