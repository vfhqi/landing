What the Triaging skeleton actually asks the Investment Analyst to write

Required Input Change Forces (Element 1) [grade]
> Element verdict [grade]. {finding, bad-news-first}
- Required Attribute 1 / Core Question 1 - {short label}
  [grade]: {verdict + evidence}
- {...minimum bullets per stage floor, double weight...}
- Counter-view considered: {...}
- Downstream actions: (1) ...; (2) ...

-> One verdict line plus as many bullets as the stage floor
   requires (3 at Triaging, 4 at Early-Stage Assessment,
   5 at Deep Dive, doubled on this Element) - not one bullet
   per Core Question. The Investment Analyst selects the most
   material Required Attribute / Core Question combinations;
   the rest of the question bank stays implicit.
Practical read. The Required Attributes and Core Questions are the Investment Analyst's internal thinking scaffold, the full set of things to have considered before writing a verdict. The memo itself only ever surfaces a stage-appropriate minimum, doubled or quadrupled on the weighted Elements. Two memos on the same Element can legitimately foreground different Required Attributes and Core Questions from the bank, provided the floor is met.
